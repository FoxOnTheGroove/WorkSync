# 6회차 · 충돌 엔진 (`ebs_simulate_collide.py`)

> 목표: 5회차의 세 판정 — **`check_collision`(면이 막혔나)**, **`measure_faces`(얼마나 여유 있나)**, **`check_equipment`(장비를 뚫나)** — 가 각각 **무엇을 무엇과 어떻게 비교하는지** 설명할 수 있게.
> 시간: 약 1시간 30분. **최적화 세부(격자, 빠른 변환)는 "왜 있는지" 만** 알고 넘어간다. 기하 판정 함수(분리축, 선분-삼각형)는 이름과 역할만.

---

## 0. 큰 그림

```
              EBS 로컬 공간 (EBS 상자 + 자세)
                 ┌────────────┐  ← ceiling 칸 (얇은 상자)
       left 칸 ▐ │    EBS     │ ▌ right 칸
                 └────────────┘
check_collision : 세 "칸" 에 다른 물체의 삼각형이 들어오나?        → True/False
measure_faces   : 칸이 비었으면 바깥으로, 막혔으면 안으로 뻗은 직육면체에서
                  가장 가까운(깊은) 점은 몇 m?                    → 거리, 프림, 점
check_equipment : EBS 의 삼각형과 대상 장비의 삼각형이 서로 교차하나? → 쌍, 상자
```

- 모든 함수가 `@classmethod` 이고 첫 인자로 **`sim`(EbsSimulate)** 을 받는다. 상태(캐시)는 전부 `sim` 쪽에 있다. 그래서 `Collide._xxx(self, …)` 꼴로 불린다.
- 판정은 **"후보 좁히기 → 정밀 검사"** 두 단계가 반복된다. 후보는 상자(AABB) 겹침으로, 정밀은 삼각형으로.

## 1. 캐시 지도 (15분) — 먼저 이걸 본다

엔진이 빠른 이유는 대부분 캐시다. **어떤 캐시가 언제 버려지나** 가 버그의 단골이다.

| `sim.` 캐시 | 담는 것 | 만드는 곳 | 버리는 곳 |
|---|---|---|---|
| `_bounds` | 안 움직이는 것용 BBoxCache (extentsHint 사용) | `_bounds_cache` (24) | init |
| (매번 새로) | 움직이는 EBS 용 BBoxCache | `_moving_cache` (860) | — |
| `_ebs_box` | EBS 의 정확한 BBox3d (extentsHint 안 씀) | `_ebs_bound` (185) | 배치·가시성 변경 시 |
| `_stage_index` | 스테이지 상자 목록 (2회차) | `_stage_boxes` (1116) | init |
| `_leaves` | `{뿌리경로: [잎(path, box, prim, chain)]}` | `_subtree_leaves` (1175) | `_forget_leaves` |
| `_local` | `{메시경로: (points, counts, indices)}` 로컬 점·면 | `_mesh_local` (711) | init |
| `_faces` | `{메시경로: 면별 로컬 상자 + 격자}` | `_face_grid` (242) | init |
| `_triangles` | `{메시경로: [(월드삼각형, lo, hi)]}` | `_mesh_triangles` (786) | `_forget_triangles` (EBS 이동 시) |
| `_parts` | `{메시경로: 삼각형별 덩어리 번호}` | `_parts_of` (931) | init |
| `_visible` | `{경로: 보이나}` | `sim._is_visible` | `check_collision` 시작, `_forget_ebs` |
| `_boxed` | `{이유: [경로]}` 삼각형 없이 상자로 판정한 것 | `_mesh_local`, `_mover` | `_begin` |
| `_face_planes` | `{면: (축, 바깥방향, 면좌표, 행축, 열축)}` | `_build_cells` (79) | 매 판정 |

> 정리: **장비 쪽은 한 번 읽으면 계속 쓰고, EBS 쪽은 움직일 때마다 버린다.**

- `_ebs_bound` : EBS 는 extentsHint 가 틀린 경우가 있어 **실측 바운드** 를 쓴다. 힌트와 1% 넘게 다르면 notes 에 경고.
- `_mesh_local` : Mesh 면 점·면 데이터, **Cube 면 `_cube_local` 로 8점 6면을 만들어** 메시처럼 다룬다. 그 외 도형(Capsule, Cylinder…)은 None → `_boxed` 에 "a Capsule" 식으로 기록.

## 2. 후보 모으기 (15분)

### 2-1. 두 갈래 — `_gather_nearby` (524)
- **`roots` 없음** → `_from_index` (499) : **스테이지 상자 목록**(`_index_inside`, 562)에서 검색 상자에 걸리고 보이는 항목을 고른 뒤, 항목마다 아래 잎을 모은다.
- **`roots` 있음** → 그 뿌리들 아래 잎만 (`_subtree_leaves`). 옆 장비 한정, EBS 자체, 대상 장비 자체에 쓴다.
- 공통 필터: `skip` 경로와 그 아래 제외, 검색 상자와 겹침(`_overlaps`), 자신과 조상이 모두 보임.
- 반환 `([(경로, 월드상자)], 본 개수)`.

### 2-2. `_subtree_leaves(root)` (1175)
- 뿌리 아래를 내려가며 **지오메트리 타입(`GEOMETRY_TYPES`)** 을 만나면 잎으로 담고 멈춤.
- 우리 프림(`OURS`), `SKIP_TYPES`, `*Light`, 빈 상자는 뺌.
- 공유 캐시(`_bounds`)를 쓸 때만 `_leaves` 에 저장 (EBS 처럼 움직이는 것은 저장 안 함).

### 2-3. 정밀 검사 전 1차 필터 — `_faces_near` (388), `_face_grid` (242)
- 큰 메시의 모든 삼각형을 월드로 바꾸면 느리다. 그래서 **로컬 공간에서 면(폴리곤)마다 상자를 재 격자에 담아 두고**, 검색 상자를 메시 로컬로 끌어와(`_pulled_back`) 근처 면만 고른다.
- `_triangles_reaching(path, box)` (1316) : 그 면들만 월드로 바꿔(`_mover`, 빠른 행렬곱) 상자에 닿는 삼각형만 돌려준다. `_triangles` 캐시가 있으면 거기서 거른다.

## 3. `check_collision` — 세 면이 막혔나 (20분) (1376)

### 3-1. 칸 만들기 — `_build_cells` (79)
- 축: up 축(Z-up 이면 Z), **front = 3 − up**, **side = 남은 축**. Z-up 이면 side=X, front=Y.
- 칸 셋 (EBS **로컬** 공간):

  | 면 | 고정 축 | 방향 | 크기 |
  |---|---|---|---|
  | right | side | + | EBS 의 up × front 넓이, 두께 t |
  | left | side | − | 〃 |
  | ceiling | up | + | EBS 의 front × side 넓이, 두께 t |

- 두께 **t = 탐침 깊이 `_probe_depth`** = EBS 최장변 × `PROBE_RATIO`(0.01).
- 같이 `sim._face_planes` 를 채운다 → `measure_faces` 와 패널 위치(7회차)가 쓴다.

### 3-2. 흐름
1. `_visible` 캐시를 비운다 (가시성은 판정마다 새로).
2. EBS 바운드 → 로컬 상자 + 월드 행렬 + 월드 정렬 상자.
3. 칸 셋을 월드 정렬 상자로 (후보 겹침 검사용).
4. 검색 상자 = EBS 월드 상자 + 탐침 깊이 여유.
5. **`_by_face`** (118) : 좌·우는 `roots`(옆 장비) 아래만, 천장은 천장 칸 근처를 **스테이지 전체** 에서. 후보마다 `(경로, 상자, 이 후보가 볼 면들)`.
6. 검출: 후보 상자가 아직 안 막힌 칸과 겹치면 → **월드 삼각형** 을 읽어 삼각형 상자 → **`_triangle_hits_box`**(분리축 정리) 로 칸과 실제로 겹치나. 한 면이 막히면 그 면은 더 안 본다.
7. 삼각형이 없는 후보(도형)는 **상자 겹침만으로 막힘** 처리 (`boxed_only`, notes).
8. `sim._blockers[면] = 처음 막은 경로` — 패널의 "무엇에 막혔나" 에 쓴다.
9. 반환 `{left: bool, ceiling: bool, right: bool}`.

## 4. `measure_faces` — 여유 거리 (20분) (1552)

### 4-1. 면마다 직육면체(prism) — `_face_prism` (376)
- **안 막힌 면** : 면에서 **바깥으로** `reach` = EBS 최장변 × `REACH_RATIO`(1.5) 만큼.
- **막힌 면(deep)** : 면에서 **안쪽으로** EBS 두께만큼 → "얼마나 파고들었나".
- 후보: `_reach_by_face` (979) — 좌·우는 옆 장비, 천장은 스테이지 전체.

### 4-2. 가장 가까운 것 — `_nearest_in_prism` (869)
1. 후보 상자를 **EBS 로컬** 로 바꿔 면까지의 상자 거리(`_gap_along`, 510)로 정렬 (deep 이면 깊은 순).
2. 앞에서부터: 상자 거리가 이미 찾은 최선보다 나쁘면 **멈춤** (조기 종료).
3. 삼각형을 EBS 로컬로 → **`_flat_gap`** (406):
   - 프리즘 발자국 안의 꼭짓점 중 면에 가장 가까운 것 (`_triangle_gap`, 1224).
   - 그 꼭짓점이 속한 **덩어리**(`_mesh_parts`, 꼭짓점을 나눠 쓰는 삼각형끼리) 안에서 **같은 깊이**(오차 `FLAT_TOL` 1%) 인 꼭짓점들을 모아 그 **가운데** 를 선 끝점으로.
   - 이유: 넓은 평면에 닿을 때 모서리 한 점이 아니라 **면 한가운데로** 안내선을 긋기 위해.
4. 삼각형이 없으면 상자 가운데 (`_box_point`).
5. 반환 `{distance, prim, at}` (deep 이면 distance 를 **음수** 로). 아무것도 없으면 `{distance: None, prim: "", reach}`.

## 5. `check_equipment` — 장비를 뚫나 (20분) (1482)

### 5-1. 흐름
1. EBS 월드 상자.
2. **ours** = EBS 아래 잎 (움직이는 캐시), **theirs** = 대상 장비 아래 잎 중 EBS 상자와 겹치는 것.
3. **`_boxed_pairs`** (59) : 한쪽이라도 삼각형 없는 도형이면 — 메시 쪽 표면이 상대 상자에 닿나(`_mesh_reaches`), 둘 다 도형이면 상자 겹침.
4. **mine** = EBS 삼각형 중 `whole`(EBS 메시 상자 합)에 닿는 것 (`_triangles_near`, 1298).
5. **`_meetings`** (641) :
   - EBS 삼각형을 **격자**(`_grid_of`, 최대 `GRID_CELLS` 24³)에 담는다.
   - 장비 메시마다: 그 상자 ∩ whole 영역 → 그 칸의 EBS 삼각형만 → 장비 삼각형(영역에 닿는 것만) 과 상자 겹침 → **`_triangles_meet`** (각 모서리를 상대 삼각형에 쏘는 선분-삼각형 교차).
   - 메시당 **처음 만난 것 하나** 만 기록 → 쌍 `(EBS 경로, 장비 경로)`. 전체 최대 `CLASH_MARKS`(200).
6. **`_missed`** (808) : EBS 상자 안에 깊숙이(각 축 50% 넘게) 들어와 있는데 표면이 안 만난 조각 → notes 경고 (안에 통째로 들어간 경우).
7. 마커용 **상자**: 걸린 장비 메시마다 실측 상자(`_mesh_box`).
8. 반환 `{hit, pairs, boxes, tests}`.

## 7. 눈에 띈 것 (참고)

- `_precision` 을 바꾸는 setter 가 없어 늘 `triangle`. `bbox`/`mesh` 갈래는 지금 안 탄다.

<summary><b>정답 (펼치기)</b></summary>

1. 엔진은 상태가 없고 캐시·설정·로그가 모두 `EbsSimulate` 에 있어서.
2. 후보는 상자(AABB) 겹침, 정밀은 삼각형 판정.
3. 공유 캐시는 바운드를 기억하므로 움직이는 EBS 에 쓰면 옛 값이 나온다. EBS 는 매번 새 캐시.
4. EBS 힌트가 실제와 다를 수 있어서. 1% 넘게 다르면 notes 에 경고하고 실측을 쓴다.
5. `_leaves` 뿌리별 지오메트리 잎, `_local` 메시 로컬 점·면 데이터, `_faces` 면별 로컬 상자와 격자, `_triangles` 월드 삼각형과 상자.
6. `_ebs_box`, EBS 아래 `_triangles` (`_forget_triangles`). (+ 가시성 변경 시 `_leaves`·`_visible` 일부)
7. Cube 는 `_cube_local` 로 8점 6면 메시처럼, Capsule 등은 데이터 None → 상자 판정(`_boxed` 기록).
8. `check_collision` 시작 때, `_forget_ebs` 에서 해당 경로.
9. roots 없음 = 스테이지 상자 목록에서(천장 등), roots 있음 = 그 뿌리 아래만(옆 장비, EBS, 대상 장비).
